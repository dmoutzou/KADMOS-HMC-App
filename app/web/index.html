    What the app does

    KADMOS computes apparent 40Ar/39Ar ages of a mineral grain by solving argon diffusion and production along a pressure–temperature–time (P–T–t) path with the finite element method. The inversion finds which combinations of initial temperature T₀, initial cooling rate, effective grain size Lr and total model time tlim are compatible with your measured age, using Hamiltonian Monte Carlo (Turing.jl). The model age compared with the measurement is the maximum apparent age in the grain.

    Workflow

    1. Setup — enter the measured age, choose the priors, path, mineral and sampler settings. Use the forward model check to see the age predicted for one set of values.
    2. Start inversion — one Markov chain runs for every random seed. With Run chains in parallel the chains use separate CPU threads.
    3. Run — follow the progress of each chain, the number of model evaluations and the log. A run can be stopped at any time (unfinished chains are not saved).
    4. Results — posterior statistics, convergence checks (R̂, ESS), interactive densities, traces and pair plots, plus all figures and tables saved in the run folder.

    Parameters

    SettingMeaning
    Observed age, uncertaintyMeasured age and its 1σ uncertainty (Myr). Gaussian likelihood.
    All four parametersUniform prior between min and max, or Gaussian (mean, σ) truncated to [min, max].
    Total model time tlimDefault: Gaussian from an independent age (e.g. hornblende) truncated at mean ± 3σ — Set limits to mean ± 3σ fills the limits. If you know a 2σ value, enter half of it as σ.
    P–T–t pathasy-CR asymptotic cooling, lin-CR linear cooling, lin-P-T linear P and T from (P₀, T₀) to (Pmin, Tmin), iso-T constant T, loaded your own table. Temperature never drops below Tmin, pressure never below Pmin.
    GeometryDiffusion domain shape: plane sheet, cylinder or sphere.
    Mineral systemDiffusion parameters (D₀, Ea, Va, reference pressure). custom uses your own values.
    Samples per chainNumber of draws kept per chain. NUTS adapts its step size during an additional warm-up phase.
    Random seedsOne chain per seed. Use ≥ 4 chains to judge convergence with R̂.
    nt, nels, θ, RdXTime steps, number of elements, time-integration parameter and grid refinement of the diffusion solver.
    Linear solverDirect uses the fast derivative-aware sparse solve of the new KADMOS code. Cholesky can only be used for the forward model check: the sparse Cholesky factorisation does not support the dual numbers used for HMC gradients.

    Reading the results

    • R̂ (potential scale reduction) compares chains: values below 1.01 are good, above 1.05 the chains have not converged — run longer or check the priors.
    • ESS (effective sample size) is the number of independent draws equivalent to the correlated chain. Aim for several hundred.
    • Divergences (numerical errors) indicate regions the sampler could not explore well.
    • The densities show the pooled posterior (all chains); thin lines are the individual chains, the dashed line is the prior.

    Output files (in results/<run name>)

    posterior_samples.csv, run_summary.txt, rhat_values.csv for every chain (chain 1 in the run folder, chain k in chain_k/); pooled density_plots and trace_plots; chain_comparison_*, chain_autocorrelation, multichain_diagnostics.csv, run_statistics.txt; and config.json with all settings so a run can be reloaded with Load settings.
